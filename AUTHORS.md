# Project Authors

This project was started by Jelle Poland and Bart van de Lint in 2026 with the goal
to provide a Julia package for simulation and validation of the TU Delft V3 leading
edge inflatable (LEI) kite, built on
[SymbolicAWEModels.jl](https://github.com/OpenSourceAWE/SymbolicAWEModels.jl).
